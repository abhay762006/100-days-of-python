# 🧩 Day 06 - Reeborg's World Maze

## 📖 Project Overview
This project is my solution to the **Reeborg's World Maze** challenge from the **100 Days of Python Bootcamp**.

## 🌐 Platform
This code only works on **Reeborg's World** because it uses functions provided by the platform, such as:
- `move()`
- `turn_left()`
- `front_is_clear()`
- `right_is_clear()`
- `at_goal()`
## 🔗 Challenge Link
https://reeborg.ca/reeborg.html?lang=en&mode=python&menu=worlds%2Fmenus%2Freeborg_intro_en.json&name=Maze&url=worlds%2Ftutorial_en%2Fmaze1.json

## 📂 Files
- `maze.py` → Python solution for the maze.
- `completed-maze.png` → Screenshot of the completed challenge.

## ▶️ How to Run
1. Open the challenge using the link above.
2. Copy the code from `maze.py`.
3. Paste it into the Reeborg editor.
4. Click **Run**.
