# Caesar Cipher 🔐

A Python implementation of the Caesar Cipher encryption and decryption algorithm built as part of the **100 Days of Code: Python Bootcamp**.

## Features

- Encrypts messages
- Decrypts messages
- Supports custom shift values
- Wraps letters correctly using modulo (`%`)
- Preserves spaces, numbers, and special characters
- Allows repeated encryption/decryption without restarting the program

## Concepts Practiced

- Functions
- Loops
- Conditionals
- Lists
- String manipulation
- Modulo operator (`%`)
- Importing modules
- User input
- Code organization

## How to Run

```bash
python main.py
```
