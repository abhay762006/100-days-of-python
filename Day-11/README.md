# 🃏 Blackjack Game

A simple command-line Blackjack game built with Python.

## 🎮 About the Project
This project is a Python implementation of the classic Blackjack card game.
The player plays against the computer and tries to get as close to 21 as possible without going over.

## ✨ Features

- Random card dealing
- Player receives two starting cards
- Computer receives two starting cards
- Player can draw additional cards
- Computer follows the Blackjack dealer rule
- Score calculation
- Blackjack detection
- Bust detection
- Winner comparison
- Ace can be treated as 1 or 11

## 🛠️ Technologies Used

- Python
- Random module
- ASCII Art
