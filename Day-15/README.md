# ☕ Coffee Machine

A Python-based coffee machine simulation that allows users to order **espresso, latte, or cappuccino**. The program checks available resources, processes coin payments, calculates change, updates the machine's resources, and tracks total profit.

## Features

* ☕ Choose between espresso, latte, and cappuccino
* 💧 Checks whether enough ingredients are available
* 🪙 Accepts quarters, dimes, nickels, and pennies
* 💰 Calculates payment and change
* 📊 Displays a resource report
* 💵 Tracks total profit
* 🔌 Includes an `off` command to shut down the machine

## Available Commands

* `espresso` — Make an espresso
* `latte` — Make a latte
* `cappuccino` — Make a cappuccino
* `report` — Display remaining resources and profit
* `off` — Turn off the machine
