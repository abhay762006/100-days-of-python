# ☕ Day 16 – Coffee Machine Using OOP

## 📌 Project Overview

This project is a **Coffee Machine simulation built using Python and Object-Oriented Programming (OOP)**.

The project simulates a real coffee machine where the user can select different drinks, insert money, check available resources, and receive their coffee if all the required conditions are satisfied.

## 🧠 What I Learned

In this project, I was introduced to the concept of **Object-Oriented Programming in Python**.

I learned how different parts of a program can be organized using **classes and objects**, instead of keeping everything inside one large Python file.

The project includes different classes responsible for different parts of the coffee machine, such as:

* ☕ Coffee menu
* 💰 Money handling
* 🧾 Coffee machine operations
* 🥛 Resources and ingredients

## 👨‍🏫 Learning Process

This project was completed with the guidance of my tutor.

For this project, my tutor provided the required classes and files and explained how they work together. My main focus was understanding the structure of the project and learning how the `main.py` file interacts with the different classes.

This means I am **still learning OOP rather than claiming that I built all the classes independently**.
