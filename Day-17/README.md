
# Quiz Game using Python OOP

## 📌 Description

A simple **Quiz Game** built using Python and Object-Oriented Programming (OOP) concepts.

The game asks the user a series of questions, checks the user's answers, and keeps track of the score.

## 🧠 OOP Concepts Used

* **Class** — Used to create the structure of the quiz questions and quiz.
* **Object** — Used to create individual question objects.
* **Constructor (`__init__`)** — Used to initialize the data of each question.
* **Methods** — Used to perform actions such as displaying questions and checking answers.
* **Attributes** — Used to store question text, answer, and score.

## 🎮 How the Game Works

1. A list of questions is created.
2. Each question is converted into a Question object.
3. The quiz asks each question one by one.
4. The user's answer is checked.
5. The score is updated for every correct answer.
6. The final score is displayed at the end.

## 🛠️ Technologies Used

* Python 3
* Object-Oriented Programming

## ▶️ How to Run

Clone or download the project and run:
